# Ligero

Ligero es una aplicación web gratuita para comprimir videos directamente en el navegador, sin subir archivos a un servidor. Sin cuentas, anuncios ni marcas de agua: tus videos permanecen en tu dispositivo.

Permite arrastrar o seleccionar un video, elegir un tamaño objetivo aproximado en MB y ajustar la resolución a 720p, 1080p u original. Muestra el progreso de compresión, permite cancelar el proceso y ofrece la descarga del resultado en formato MP4, listo para compartir.
